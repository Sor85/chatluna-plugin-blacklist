# ChatLuna Blacklist

ChatLuna 插件，让机器人自己拉黑辱骂、骚扰它的用户。拉黑由模型自行判断并调用工具，必须填写理由；已拉黑用户的消息不再进入对话，指令也不执行，直到解除拉黑。黑名单保存在数据库中，可通过工具或管理指令查看。

## 功能

- `blacklist_user`：拉黑用户，参数为理由（必填）、可选的拉黑时长、用户 ID、名称和平台；时长以分钟计，不填或填 0 为永久；用户 ID 默认为当前对话的用户，平台默认取当前会话
- `unblacklist_user`：解除拉黑
- `list_blacklisted_users`：列出已拉黑用户的名称、ID、平台、理由、拉黑时间和期限，可按平台筛选
- 已拉黑用户的消息既不唤醒模型，也不写入会话记录；默认同时屏蔽其指令
- 限时拉黑到期后自动失效，无需手动解除
- 任何用户都可能被拉黑（包括管理员），只有机器人自身不能被拉黑；重复拉黑保留原理由和期限，不覆盖
- 黑名单按“平台＋用户 ID”记录，对该平台下所有群聊和私聊生效

## 设置页黑名单

插件设置页底部逐行显示当前生效的黑名单：用户名称与 ID、平台、理由、拉黑时间和期限，限时拉黑显示剩余时间。列表随拉黑与解除实时更新，限时拉黑到期后自动移出。每行可直接解除拉黑，确认后立即生效，无需保存配置。需要加载 ChatLuna WebUI。

## 权限

| 权限项 | 默认等级 | 说明 |
| --- | --- | --- |
| `blacklist:add` | 1 | 调用 `blacklist_user` |
| `blacklist:remove` | 1 | 调用 `unblacklist_user` |
| `tool:list_blacklisted_users` | 1 | 调用 `list_blacklisted_users` |

工具调用时的身份是当前与机器人对话的用户，被拉黑的通常就是调用者本人，所以默认等级为 1，由模型自行判断。调高等级会让机器人无法拉黑普通用户。工具的启用范围在工具管理页设置。

## 管理指令

供人工查看和撤销机器人的拉黑记录，需要 Koishi 兼容层，权限等级 3 及以上可用：

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `blacklist` | `黑名单` | 查看已拉黑用户列表 |
| `blacklist.add [-t 时长] <用户> <理由>` | `拉黑` | 拉黑用户，理由必填；`-t` 指定时长，如 `30m`、`2h`、`1d`，默认永久 |
| `blacklist.remove <用户>` | `解除拉黑` | 解除拉黑 |

用户参数使用 @ 提及，或写作 `@用户ID`。`-t` 须写在理由之前，否则会被当作理由的一部分。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `blockCommands` | `true` | 屏蔽已拉黑用户的指令；关闭后只屏蔽对话 |

## 与 `chatluna.ban` 的区别

`chatluna.ban` 写入一条 `deny *` 权限规则，拒绝用户使用指令和工具，但不阻止对话。本插件的黑名单直接拦截对话消息，并记录拉黑理由，两者可同时使用。
